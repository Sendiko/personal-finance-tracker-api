Personal Finance Tracker API Documentation

This document outlines the API endpoints for the Personal Finance Tracker.
Base URL: https://fintrack.sendiko.my.id

1. User Endpoints

POST /register

Description: Registers a new user.

Request Body (JSON):

                {
                    "name": "Sendiko",
                    "email": "rizkysendiko7@gmail.com",
                    "password": "00119922"
                }

Authentication: None

POST /login

Description: Logs in an existing user and returns an authentication token.

Request Body (JSON):

                {
                    "name": "Sendiko",
                    "password": "00119922"
                }

Authentication: None

PUT /users/{userId}

Description: Updates an existing user's information. Replace {userId} with the actual user ID.

Request Body (JSON):

                {
                    "name": "Sendikoo"
                }

Authentication: Bearer Token (e.g., eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJuYW1lIjoiU2VuZGlrbyIsImlhdCI6MTc0OTQ0MDU0MH0.vNXODtOAKgDsaq4wdME5Qc5ExU-m2QtIg8X0Usl-1KA)

2. Wallet Endpoints

GET /wallets/

Description: Retrieves all wallets for the authenticated user.

Authentication: Bearer Token

POST /wallets

Description: Creates a new wallet.

Request Body (JSON):

                {
                    "name": "Daily Spending",
                    "purpose": "Spending",
                    "type": "card",
                    "balance": 0.0,
                    "userId": "6ac6b327-47c0-4e8a-adbb-4c1b075f162c"
                }

Authentication: Bearer Token

PUT /wallets/{walletId}

Description: Updates an existing wallet's information. Replace {walletId} with the actual wallet ID.

Request Body (JSON):

                {
                    "type": "e-money"
                }

Authentication: Bearer Token

3. Category Endpoints

GET /categories/{userId}

Description: Retrieves all categories for a specific user. Replace {userId} with the actual user ID.

Authentication: Bearer Token

Description: Creates a new category.

                }

PUT /categories/{categoryId}

Description: Updates an existing category's information. Replace {categoryId} with the actual category ID.

Request Body (JSON):

                {
                    "name": "Foods and Beverages"
                }

Authentication: Bearer Token

4. Transaction Endpoints

GET /transactions/{userId}

Description: Retrieves all transactions for a specific user. Replace {userId} with the actual user ID.

Authentication: Bearer Token

Description: Creates a new transaction.

PUT /transactions/{transactionId}

Description: Updates an existing transaction's information. Replace {transactionId} with the actual transaction ID.

Description: Deletes a specific transaction. Replace {transactionId} with the actual transaction ID.

Authentication: Bearer Token

5. Budget Endpoints

Budgets are general user-level limits and are not tied to a wallet. All non-transfer expense transactions across the user's wallets count toward the budget. Dates are inclusive and use YYYY-MM-DD.

GET /budgets

Description: Retrieves all budgets for the authenticated user with current spending summaries.

Summary fields: totalAmount, spent, remainingAmount, remainingDays, todayBudget, spentToday, remainingToday, and isActive.

Authentication: ******

GET /budgets/{budgetId}

Description: Retrieves one budget and its current spending summary.

Authentication: ******

GET /budgets/today

Description: Finds the authenticated user's budget whose inclusive date range contains today and returns today's allowance and spending summary.

Calculation: todayBudget = remainingAmount / remainingDays. This recalculates after spending, redistributing the remaining amount over the remaining timeline.

                {
                    "status": 200,
                    "message": "Today's budget sent successfully.",
                    "summary": {
                        "totalAmount": 3000000,
                        "spent": 450000,
                        "remainingAmount": 2550000,
                        "remainingDays": 25,
                        "todayBudget": 102000,
                        "spentToday": 25000,
                        "remainingToday": 77000,
                        "isActive": true
                    }
                }

Authentication: ******

POST /budgets

Description: Creates a general budget for the authenticated user.

Request Body (JSON):

                {
                    "amount": 3000000,
                    "startDate": "2026-11-01",
                    "endDate": "2026-11-30"
                }

Validation: amount must be greater than zero, dates must be valid, and startDate cannot be after endDate.

Authentication: ******

PUT /budgets/{budgetId}

Description: Updates a budget. Any subset of amount, startDate, and endDate may be provided.

                {
                    "amount": 3500000,
                    "endDate": "2026-12-05"
                }

Authentication: ******

DELETE /budgets/{budgetId}

Description: Deletes a budget.

Authentication: ******
