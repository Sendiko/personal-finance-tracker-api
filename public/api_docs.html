Fintrack developer reference

Personal Finance Tracker API Documentation

Build secure, connected financial experiences with the Fintrack REST API. Browse authentication, wallets, transactions, transfers, and budget endpoints below.

Base URL  https://fintrack.sendiko.dev/api/

1. User Endpoints

POST /register

Description: Registers a new user.

Request Body (JSON):

                {
                    "name": "Sendiko",
                    "email": "rizkysendiko7@gmail.com",
                    "password": "00119922"
                }

Authentication: None

POST /login

Description: Logs in an existing user and returns an authentication token.

Request Body (JSON):

                {
                    "name": "Sendiko",
                    "password": "00119922"
                }

Authentication: None

PUT /users/{userId}

Description: Updates an existing user's information. Replace {userId} with the actual user ID.

Request Body (JSON):

                {
                    "name": "Sendikoo"
                }

2. Wallet Endpoints

GET /wallets/

Description: Retrieves all wallets for the authenticated user.

Authentication: Bearer Token

POST /wallets

Description: Creates a new wallet.

Request Body (JSON):

                {

                    "type": "card",
                    "balance": 0.0,
                    "userId": "6ac6b327-47c0-4e8a-adbb-4c1b075f162c"
                }

Authentication: Bearer Token

PUT /wallets/{walletId}

Description: Updates an existing wallet's information. Replace {walletId} with the actual wallet ID.

Request Body (JSON):

                {
                    "type": "e-money"

4. Transaction Endpoints

GET /transactions

Description: Retrieves the authenticated user's transactions. Optional query parameters: startDate, endDate, and type (income or expense).

Examples: /transactions?startDate=2026-11-01&endDate=2026-11-30&type=expense or /transactions?type=income&type=expense

Authentication: Bearer Token

POST /transactions

Description: Creates a new transaction.

Request Body (JSON):

                {
                    "name": "Luch at KFC",
                    "amount": 50000,
                    "type": "expense",
                    "categoryId": "70b92638-f06a-4d1a-b5f7-56ae7de4dc18",
                    "walletId": "afc42d8c-c3e1-43a1-aaff-0b01d1458bc9",
                    "userId": "6ac6b327-47c0-4e8a-adbb-4c1b075f162c"
                }

Authentication: Bearer Token

PUT /transactions/{transactionId}

Description: Updates an existing transaction's information. Replace {transactionId} with the actual transaction ID.

Request Body (JSON):

                {
                    "name": "Lunch at KFC"
                }

Authentication: Bearer Token

DELETE /transactions/{transactionId}

Description: Deletes a specific transaction. Replace {transactionId} with the actual transaction ID.

Authentication: Bearer Token

5. Transfer Endpoints

Transfers create a linked expense transaction and income transaction with isTransfer: true. Wallet balances are updated atomically.

GET /transfers

Description: Retrieves transfers for the authenticated user.

Authentication: Bearer Token

POST /transfers

Description: Creates a transfer between two wallets and updates both balances.

{
    "amount": 50000,
    "sourceWalletId": "source-wallet-id",
    "destinationWalletId": "destination-wallet-id",
    "categoryId": "category-id"
}

Authentication: Bearer Token

PUT /transfers/{transferId}

Description: Updates a transfer and recalculates both wallet balances.

Authentication: Bearer Token

DELETE /transfers/{transferId}

Description: Deletes a transfer and reverses its balance changes.

Authentication: Bearer Token

6. Budget Endpoints

Budgets are general user-level limits and are not tied to a wallet. All expense transactions across the user's wallets count toward the budget. Dates are inclusive and use YYYY-MM-DD.

GET /budgets

Description: Retrieves all budgets for the authenticated user with current spending summaries.

Summary fields: totalAmount, spent, remainingAmount, remainingDays, todayBudget, spentToday, remainingToday, dailyPercentageUsed, totalPercentageUsed, and isActive. Percentage fields are rounded integers from 0 to 100.

Authentication: Bearer Token

GET /budgets/{budgetId}

Description: Retrieves one budget and its current spending summary.

Authentication: Bearer Token

GET /budgets/today

Description: Finds the authenticated user's budget whose inclusive date range contains today and returns today's allowance and spending summary.

Calculation: todayBudget = remainingAmount / remainingDays. This recalculates after spending, redistributing the remaining amount over the remaining timeline.

                {
                    "status": 200,
                    "message": "Today's budget sent successfully.",
                    "summary": {
                        "totalAmount": 3000000,
                        "spent": 450000,
                        "remainingAmount": 2550000,
                        "remainingDays": 25,
                        "todayBudget": 102000,
                        "spentToday": 25000,
                        "remainingToday": 77000,
                        "dailyPercentageUsed": 24,
                        "totalPercentageUsed": 15,
                        "isActive": true
                    }
                }

Authentication: Bearer Token

POST /budgets

Description: Creates a general budget for the authenticated user.

Request Body (JSON):

                {
                    "amount": 3000000,
                    "startDate": "2026-11-01",
                    "endDate": "2026-11-30"
                }

Validation: amount must be greater than zero, dates must be valid, and startDate cannot be after endDate.

Authentication: Bearer Token

PUT /budgets/{budgetId}

Description: Updates a budget. Any subset of amount, startDate, and endDate may be provided.

                {
                    "amount": 3500000,
                    "endDate": "2026-12-05"
                }

Authentication: Bearer Token

DELETE /budgets/{budgetId}

Description: Deletes a budget.

Authentication: Bearer Token

7. Spending Analysis

Returns expense spending grouped by category, category budget percentages, and a rolling six-month history with the month-over-month change percentage. Transfers are excluded.

GET /analysis/spending

Description: Retrieves the authenticated user's spending analysis.

Query parameters: range accepts month (default), week, or custom. For custom, provide both startDate and endDate in YYYY-MM-DD format.

Examples: /analysis/spending?range=week or /analysis/spending?range=custom&startDate=2026-11-01&endDate=2026-11-15

Authentication: Bearer Token
